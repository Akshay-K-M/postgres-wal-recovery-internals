PostgreSQL Recovery Lab

Write a scenario. It runs for real on a fresh PostgreSQL cluster, one step per click.

How to write it

T1: INSERT …;
Runs in session T1. Every name is its own connection, so T1 can stay open while others run.
CHECKPOINT;
No name: runs in a one-off session.
crash
Kills the server (immediate shutdown). The next clicks step through the real recovery, paused in gdb.
-- note
A caption shown with the next step.

Statements end with ; and may span several lines.
